# Section 6.1 — Entity

## Fill rules

- **Location:** `lib/domain/entities/{domain}/{name}.dart` (always domain layer — no `lib/features/` or `lib/shared/`).
- **Shape:** `abstract class` with getters — **no** `@freezed`, **no** `fromJson`, **no** Flutter imports.
- **Name:** PascalCase, no `Model` / `Entity` suffix (e.g. `Login`, `Account`).

## Review rules

- [ ] Path under `lib/domain/entities/`.
- [ ] Abstract class; no JSON annotations.
- [ ] Concrete Dart types only — no `dynamic`.
