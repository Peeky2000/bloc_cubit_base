# Section 6.10 — Route

## Fill rules

- **Path constant:** `AppPage.{NAME}` in `lib/core/common/route.dart` (e.g. `SIGN_IN = '/sign_in'`).
- **Registration:** `SLIPage(name: AppPage.X, page: xScreenBuilder())` in `AppPage.pages`.
- **Navigation:** `SLIRouting.toNamed`, `offNamed`, `offAllNamed` with `arguments: { ... }` map.
- **Not go_router** — do not specify `GoRoute` or `context.go`.

## Review rules

- [ ] Path string starts with `/`.
- [ ] Consistent with §5.2 navigation flows.
- [ ] Params documented as `arguments` keys screens read.
