# Section 6.2 — Model

## Fill rules

- **Location:**
  - Response: `lib/data/model/response/{domain}/{name}_response_model.dart`
  - Request: `lib/data/model/request/{name}_request_model.dart`
- **Shape:** `@JsonSerializable()` class, often `implements` entity from §6.1.
- **Codegen:** `json_serializable` → `*.g.dart` (not `@freezed`).
- **Fields:** `@JsonKey(name: 'snake_case')` when API key differs.

## Review rules

- [ ] 1:1 with §6.1 entities where applicable.
- [ ] Path under `lib/data/model/`.
- [ ] No business logic in model class.
