# Section 6.3 — Repository & UseCase

## Fill rules

### Repository

- **Interface:** `lib/domain/repositories/{name}_repo.dart` — `abstract class`
- **Impl:** `lib/data/repositories/{name}_repo_impl.dart`
- Returns entity types or models that implement entities — no UI logic.

### UseCase (required in this base)

- **Location:** `lib/domain/use_case/{name}_use_case.dart`
- **Role:** Business orchestration; Cubit calls UseCase, **not** Repo directly.
- List public methods Cubit will call.

## Review rules

- [ ] Interface in `domain/repositories/`, impl in `data/repositories/`.
- [ ] Every feature flow has a UseCase entry with methods listed.
- [ ] No `BuildContext` in UseCase/Repo.
