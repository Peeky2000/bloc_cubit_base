# Section 6.4 — API / DataSource

## Fill rules

- **Remote:** `lib/data/datasource/remote/{name}_remote_data_source.dart` (abstract + impl).
- **Local:** `lib/data/datasource/local/` when caching tokens/settings.
- **HTTP:** `ApiHandler` (`ApiClient`) — method, path via `UrlEndPoint`, parser → Model from §6.2.
- **Not Retrofit** — document endpoint as: `POST /path`, body fields, response model name.

## Review rules

- [ ] Paths under `data/datasource/`.
- [ ] Each endpoint maps to a response model in §6.2.
- [ ] No business validation in data source (belongs in Cubit or UseCase).
