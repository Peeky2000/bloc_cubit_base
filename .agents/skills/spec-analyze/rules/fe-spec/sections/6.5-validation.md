# Section 6.5 — Validation

## Fill rules

- **Where:** Form validation in **Cubit** (see `SignInCubit`) using regex from `lib/core/common/constant.dart`.
- **i18n:** ARB keys in `lib/l10n/arb/` — reference key name (e.g. `passIsRequired`), not `easy_localization`.
- **State:** Field errors on Cubit state (`errorUsername`, …) — not only global dialog.

## Review rules

- [ ] Error messages reference `context.l10n` / ARB keys.
- [ ] No `lib/shared/validators/` unless team adds that folder later.
