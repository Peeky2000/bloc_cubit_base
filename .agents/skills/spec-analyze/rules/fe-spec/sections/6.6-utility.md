# Section 6.6 — Utility

## Fill rules

- **Infrastructure:** `lib/core/helper/`, `lib/core/extension/`, `lib/core/common/`
- **App-level:** `lib/widget/` or `modules/sli_common/`
- **Not** `lib/shared/utils/` or `lib/features/.../utils/` unless created explicitly for a feature under `presentation/{feature}/`

## Review rules

- [ ] Path exists or is justified as new file under `core/` or feature presentation folder.
