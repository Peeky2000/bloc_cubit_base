# Section 6.8 — Cubit

## Fill rules

- **Default:** `Cubit` extending `BaseCubit<State>`.
- **Location:** `lib/presentation/{feature}/cubit/{feature}_cubit.dart` + `{feature}_state.dart` (part).
- **State:** extends `BaseAppState`, uses `LoadingStatus`, `copyWith`, `EquatableMixin`.
- **Dependencies:** constructor-injected `UseCase` — **not** Repository or service locator.
- **Errors:** typed/recoverable errors in state; UI listener owns presentation effects.
- **Alternative:** classic BLoC is allowed when event concurrency is documented.

## Review rules

- [ ] No `@freezed` requirement — use immutable `BaseAppState + Equatable + copyWith`.
- [ ] `loading` / `complete` / `error` via `LoadingStatus`.
- [ ] Methods match user actions in §6.9.
