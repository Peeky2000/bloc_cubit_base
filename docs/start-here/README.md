# Bắt đầu từ đây

Thư mục này dành cho người: đọc từ trên xuống là biết base có gì, chạy thế
nào, làm tính năng ra sao và dùng công cụ nào. Mỗi trang ngắn, chỉ nêu cái cần
biết rồi trỏ sang tài liệu chi tiết.

| 2 | [Cài và chạy](02-cai-va-chay.md) | Cần cài gì, clone rồi chạy app thế nào |

| 4 | [Làm một tính năng](04-lam-mot-tinh-nang.md) | Từ spec tới code: lệnh nào, ai làm gì, mình duyệt gì |
| 5 | [Agent, skill và luật](05-agent-skill-luat.md) | AI trong repo gồm gì, gọi thế nào, luật nằm đâu |
